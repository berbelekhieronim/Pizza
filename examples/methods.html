Sample sizes: how they are worked out

Every sample size on these pages (Explore: Ideas to test and Leads; docs/sample-sizes.md) is the number of people that gives an 80% chance (power) of a significant result, two-sided, if the true effect is the one stated. Assumptions: independent people, one pizza each, equal groups unless stated, no dropouts (recruit about 3 times as many to allow for people who do not finish).

Two groups (Mann-Whitney, Cliff's δ)
n per group = 2 (zα/2 + zβ)² / (3 δ²)		Noether (1987) for the Mann-Whitney test with equal groups, written with Cliff's δ: P(group value > comparison value) = (1 + δ) / 2, and Noether's total N = (zα/2 + zβ)² / (12 c (1 − c) (P − ½)²) with c = ½ gives 2 (zα/2 + zβ)² / (3 δ²) per group. zα/2 = 1.960 (α = .05, two-sided), zβ = 0.842 (power .80).analyse.py:3032 n_per_group()
Correlation with a self-report (Spearman ρ)
n = ((zα/2 + zβ) / atanh ρ)² + 3		Fisher's z: atanh of a correlation is about normal with SD 1 / √(n − 3). Used for Spearman ρ as an approximation.analyse.py:3038 n_for_rho()
Change within a person (sign test)
with p = (1 + d) / 2: n = (½ zα/2 + zβ √(p (1 − p)))² / (p − ½)²		d = dominance: share of people who change the expected way minus the share who change the other way. The normal approximation to the binomial (sign) test of p against ½.analyse.py:3043 n_for_change()
Several tests
α per test = .05 / t; zα/2 = Φ−1(1 − α / 2)		Planning uses Bonferroni over the t tests of an idea (or of all the ideas), which is conservative: the analysis itself uses the Benjamini-Hochberg false discovery rate, which needs a little fewer people. t = measures × comparisons.analyse.py:3027 z_alpha()
Unequal groups
total N = (equal-group total) / (4 c (1 − c)), c = the smaller group's share		From Noether's formula with c ≠ ½. A 1 : 3 split needs 1.33 times as many people in all as a 1 : 1 split; 1 : 9 needs 2.8 times.analyse.py:3032 n_per_group()

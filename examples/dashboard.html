How normal is each pizza?

Two things are compared with the reference (200 pizzas from a separate reference set). Which toppings: how surprising the set of toppings is given how often each topping appears; adding a rare topping or leaving off a near-universal one both add surprise (in bits, plotted below). How many: how extreme the number of different toppings is, in either direction, so a plain pizza or one with everything stands out. Each becomes a percentile of the reference, and the band uses the more extreme of the two: under 75 is typical, 75-95 uncommon, above 95 unusual.

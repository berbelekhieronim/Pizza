Pizza profiles and clusters

Each participant's pizza is summarised as a profile of 30 measures in 9 areas. Each score is standardised across these 60 participants (0 = sample average, ±1 = one standard deviation) and signed so that higher always means more of the named trait. Profiles are grouped with hierarchical clustering (Ward's method) into 2 clusters, the number with the best average silhouette (k=2: 0.25 · k=3: 0.09 · k=4: 0.09 · k=5: 0.09 · k=6: 0.10). They are reported because the best split (k = 2, silhouette 0.25) beats the best split of each of 79 datasets with no types but the same measures and correlations (theirs: 0.10 to 0.24; p = 0.013, needed ≤ 0.0125).

Searching for types

Are there distinct types of pizza-makers, rather than people spread along continuous dimensions? Each family of measures is clustered (Ward's method, the number of clusters with the best average silhouette) and compared with 79 datasets that have no types but the same values of each measure and the same correlations between them, clustered the same way (stopping early once a family cannot pass). Four searches are tried, so a family counts only at p ≤ 0.0125 (.05 / 4). Clustering always returns groups; this is what keeps it from inventing them.
